* 👁️ **Zero "Pinch-and-Zoom" Frustration:** Pages automatically reflow and adapt to fit your screen size perfectly, with easy-to-read text, touch-friendly buttons, and effortless navigation.

* **Catalog & Master Data Management (Create, Edit & List Views):**
  * Product Management (Product List, Add/Edit Product forms)

* **Navigation Shell:** Replaces the fixed desktop sidebar with an off-canvas drawer that slides out smoothly when tapped. Workspace tabs support horizontal swiping.

* **Action Buttons:** "Save", "Cancel", and "Back" buttons wrap cleanly to the screen width and remain easily reachable without zooming.
* **Table Containment:** Data tables are enclosed in a smooth horizontal swipe container. Columns maintain a readable width, preventing character-by-character text wrapping or squished numbers.

To keep this package within the accessible $500 budget, advanced interactive workflows and cashier-specific tools remain in their original desktop design:
* ❌ **No Touch POS Cashier Order Terminal:** The main order creation & checkout screen remains in its original desktop-oriented layout. It does not include mobile touch product cards, catalog-to-cart tab toggles, or fast cashier touch workflows. *(Cashiers should continue using desktop counter PCs, or upgrade to Option 2).*
* ❌ **No Complex Multi-Item Inventory Builders:** Multi-row Stock In creation (adding multiple items, suppliers, purchase prices simultaneously), Stock Out workflows, and branch-to-branch Stock Transfers remain optimized for desktop use.
* ❌ **No Deep Financial Drill-Down Modals:** Advanced sales analytics popups (daily/monthly breakdowns, transaction modals, and historical debt payment dialogs) remain in their desktop layout.
* ❌ **No File Manager Mobile Redesign:** The popup media/image file manager remains in its 800px desktop format.
* ❌ **No Mobile Bulk Invoice Previews:** Bulk invoice printing and delivery slip previews remain desktop-only.
